# Project Setup
To setup this project we must do the following steps

## 1. Clone a Personal Fork of the Repository
First fork the repository in `https://github.com/up-csi/service-merch-store`

To clone repository we use the command
```
#clone the forked repository
git clone <your-forked-repo-link>
```

## 2. Navigate to the Project and Install the Dependencies
```
#enter the repo
cd service-merch-store

#install dependencies
pnpm install
```

## 3. Create the Environment Variables
Note: Ask a Manager of the Project for the `.env` file

## 4. Running a Local Instance
To run the local instance we use the command
```
pnpm run dev --open
```
